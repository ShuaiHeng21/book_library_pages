GitHub 书库同步

书籍、封面和笔记保存在私有仓库 ShuaiHeng21/book_library_webpage 的 data/library.json 中。手机和电脑分别登录后即可同步。

正在检查连接…

首次使用需要部署授权后端并注册 GitHub App。当前网页可独立使用本地书库；配置完成前，GitHub 登录与同步不可用。

保存书籍后自动尝试同步。离线时仍可录入，恢复网络后点击「立即同步」。两台设备修改同一本书时，由你选择保留哪个版本。登录会话最多保留 8 小时；退出不会删除书库。
